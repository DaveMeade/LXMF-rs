# LXMF-rs v0.9.9-rc.3

This candidate supersedes `v0.9.9-rc.2` for the same RNS 1.4.2 software parity
scope. The second tag built every Linux and Windows target, but its Intel
macOS job remained queued on the retired `macos-13` runner label. This
candidate uses the current `macos-15-intel` hosted runner label so the
universal macOS bundle can complete.

See [`docs/release-notes-v0.9.9-rc.2.md`](release-notes-v0.9.9-rc.2.md) for
the dbus portability correction and the complete parity scope, pinned
references, artifact policy, and deferred evidence boundaries. The workspace
and publishable crate version remains `0.9.9`; the prerelease suffix is
carried by this GitHub tag.
